# 新增紫微卡片的格局證據與四化檢視

## Why

格局規則和四化層已可從同一本命盤取得。紫微卡片要在小螢幕上讓讀者查閱傳統解讀的依據、日期及來源。

## What Changes

- 展開紫微卡片的「格局與四化」才載入並執行擴充解讀。啟用版的 PWA 會預先快取拆分後的模組。
- 提供本命、流年、流月、流日切換及坐守宮位。展開符合條件的格局可查看必要、強化、破格證據及規則來源。
- 面板日期預設跟隨儀表板，也可獨立查閱其他日期。選擇查閱日期不影響儀表板評分。缺少足以排盤的出生時間或發生錯誤時提示原因。
- 延用預設停用的 `VITE_ZIWEI_PATTERNS`。預覽建置以 `VITE_ZIWEI_PATTERNS=true pnpm build` 啟用，正式環境開啟前需完成真人可用性驗證。

## 驗證

- Chromium 正式建置預覽以 375 px 驗證明暗主題、鍵盤展開與切換、跨年和閏月日期輸入、證據與來源、缺少出生時間的提示，以及 PWA 離線重新載入後改選日期。
- 相同 Node.js 24.22.3 建置中，旗標開啟時所有 JS 與 CSS 合計 gzip 比停用版增加 6,326 bytes，面板與格局規則各自拆分。停用版的 PWA 無這兩個模組。
- 以同一合成出生盤和 228 組日期，在暖機後量測建立命盤、快照、格局與四化的額外 CPU 時間。三輪各 2,280 次，p50 為 0.040–0.045 ms，p95 為 0.886–0.890 ms。量測範圍為本機 Node.js 同步運算。
- 在啟用版的數據分析頁以 1,304 筆合成行情完成五年回測，觀測到分段計算呼叫瀏覽器排程讓出主執行緒 91 次。此項驗證使用固定合成行情。
