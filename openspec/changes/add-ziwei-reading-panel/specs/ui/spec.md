## ADDED Requirements

### Requirement: 紫微格局與四化檢視

紫微卡片 SHALL 在功能旗標啟用後提供可展開的格局與四化區域。展開後按需載入解讀，顯示已符合必要條件的格局、依據與來源，以及由使用者選擇的本命或時間層四化。

#### Scenario: 切換日期或四化層

- **WHEN** 使用者選擇本命、流年、流月或流日，或使用面板內日期欄位
- **THEN** 標籤及四化結果反映目前的選擇
- **AND** 同一個人的本命盤維持一致

#### Scenario: 缺少出生時間

- **WHEN** 出生時間缺漏或格式無效
- **THEN** 卡片說明格局與四化未計算的原因
- **AND** 原有命理卡片及投資評分維持現行行為

#### Scenario: 手機、鍵盤與離線

- **WHEN** 在寬度 375 px 的畫面以鍵盤開啟擴充區域或切換層別
- **THEN** 操作有可見焦點，內容可在畫面寬度內閱讀
- **AND** 已完成 PWA 預先快取的裝置可離線查閱解讀
