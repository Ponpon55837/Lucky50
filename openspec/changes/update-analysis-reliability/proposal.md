# 強化 0050 行情、績效與本地紀錄

## Why

FinMind 失敗時的示範價格會進入投資分析，按開盤進場的策略也可能計入進場前的隔夜漲跌。多個分頁同時保存同一日運勢時可能留下重複紀錄。最新主線已有紫微解讀面板，可沿用既有命盤展示同坐命宮的證據。

## What Changes

- 投資分析只接收可追溯的真實行情，標明取得時間、涵蓋範圍、快取與不可用狀態。核對可驗證的公司行動前收。
- 策略按開盤調倉並以收盤估值，列出交易費用與扣費前後結果。以固定行情序列獨立驗證 ATR、CCI、RSI。
- 以資料表提供價格、成交量與引擎分數圖的替代讀法。使用真實瀏覽器測試期間切換與鍵盤操作。
- 原子寫入同日同人的單筆運勢，保留批次匯入的 ID 規則。
- 在現有紫微解讀面板加入紫微、天府同坐命宮的判定，列出兩星實際落宮。

## Impact

影響儀表板、分析頁、紫微解讀與歷史儲存。回測口徑改變，既有運勢評分與使用者歷史資料沿用。
