# 新增紫微斗數流年與流月四化

## Why

紫微卡片需要將本命、流年、流月和流日的四化來源分別顯示，讓使用者查閱所選日期的傳統解讀。

## What Changes

- 由本地曆日解析農曆流年與有效流月，再沿用 Lucky50 五虎遁與十干四化。
- 四層共用同一張本命盤，位置使用星曜實際坐守地支。
- 每次依日期重算時間層。投資評分、歷史與回測流程維持原值。

## 曆法

流年以農曆正月初一換年。流月取農曆月份，閏月第 1–15 日沿用該月，第 16 日起用下一月。若閏十二月後半跨入正月，流月使用次年年干，流年仍按實際農曆年。本口徑獨立於出生月正規化。流日以本地曆日的農民曆日干為準。[上游流月四化口徑](https://github.com/Renhuai123/ziwei-doushu/blob/39c0abd3b8dac609975dddfadd4d4e1d3a978deb/lib/ziwei/sihua.ts#L86-L136)
